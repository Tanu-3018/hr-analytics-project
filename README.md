# HR Analytics Project

## 🛠 Tools Used
Python | SQL Server | Power BI

## 📋 Project Overview
End-to-end HR intelligence dashboard covering the full 
employee lifecycle — from recruitment pipeline to attrition 
analysis — using 4 interconnected datasets with 3000 
records each.

## 📊 Dashboard Pages
- Page 1: Workforce Overview
- Page 2: Attrition & Retention Analysis
- Page 3: Recruitment Pipeline

## 🔍 Key Insights
1. Overall attrition rate is 12.87%
2. Production dept has highest headcount
3. Low engagement score employees show higher attrition
4. Training completion correlates with lower attrition

## 📁 Project Structure
- python/ — Data cleaning + 10 EDA charts
- sql/ — 14 analytical SQL queries
- dashboard/ — Power BI 3-page dashboard
- charts/ — All EDA visualization outputs
